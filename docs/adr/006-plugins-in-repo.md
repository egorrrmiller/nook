# ADR-006: Плагины — статически подключённые модули, не динамические DLL

Статус: принято (2026-09-13)

Плагин = C#-проект (`IPlugin` из `Nook.Plugins.Sdk`) + TS-пакет (`@nook/plugin-sdk`). Обнаружение через DI при старте, включение/выключение в настройках. Динамическая загрузка сборок отвергнута (конфликты зависимостей, hot-reload не стоит усилий). Внешние агенты и боты работают через REST + API-токены и встроенный MCP-сервер.
