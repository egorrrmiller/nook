# ADR-001: Yjs + Hocuspocus для содержимого страниц; проекция `blocks` — производная

Статус: принято (2026-09-13)

## Контекст
Нужно одновременное редактирование одной заметки двумя людьми и работа одного человека с нескольких устройств. Per-block LWW теряет нажатия при правке одного абзаца; JSON-документ на страницу теряет данные при двух вкладках.

## Решение
Источник истины содержимого — Y.Doc (`documents.ydoc` + журнал `document_updates`). Сервер коллаборации — Hocuspocus (Node), потому что формат документа (ProseMirror-схема BlockNote) живёт в JS, а `@blocknote/server-util` даёт headless-редактор для серверных правок и конвертаций. Таблица `blocks` — производная проекция для SQL/поиска/synced blocks/экспорта, перестраивается при каждом сохранении.

## Последствия
+ Live-курсоры, presence, оффлайн-мердж, per-user undo — без кастомного sync-кода.
+ ИИ/боты/импорт пишут через `POST /internal/docs/{id}/ops`, клиенты видят мгновенно.
− Второй рантайм (Node) в деплое. Без collab страница открывается read-only из проекции.
− YDotNet (yrs в C#) отвергнут: «early», хрупкая сборка PM-схемы из C#.
