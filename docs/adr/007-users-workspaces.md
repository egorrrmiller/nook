# ADR-007: Пользователи, личные пространства, invite-only, шаринг поддеревьев

Статус: принято (2026-09-13)

Пользователей несколько (1–2 человека), регистрация только по приглашению владельца инстанса. Каждому — личное пространство; членство в пространстве (owner/editor/viewer) и `node_shares` на поддерево; эффективная роль = максимум по предкам. Публичных ссылок нет.
