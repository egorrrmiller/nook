# ADR-002: Редактор — BlockNote

Статус: принято (2026-09-13)

BlockNote 0.54+ (core MPL-2.0): блочный UX из коробки (slash, drag handle, side menu), кастомные блоки как React-компоненты, math/Mermaid, таблицы, collaboration. Пакеты `xl-*` (multi-column, docx/pdf export) — AGPL-3.0: допустимо для личного self-hosted; при публикации кода — лицензия репозитория AGPL-совместимая. Отвергнуты: Plate (Notion-шаблон Potion платный, Slate капризен на мобильном IME), TipTap/Lexical (блочный UX собирать вручную, +4–6 недель).
